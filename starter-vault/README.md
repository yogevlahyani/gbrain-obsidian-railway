# Brain vault

This is the markdown source of truth for your GBrain + Quartz stack.

- GBrain indexes these pages and commits agent writes back to git.
- Quartz publishes the same markdown as a static site.
- Edit locally in Obsidian (or any editor) and push to this repo.
- Dot-folders such as `.obsidian/` are not indexed by GBrain or copied into Quartz content.
