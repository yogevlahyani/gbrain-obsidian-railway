# Brain vault

This is the markdown source of truth for your GBrain + Obsidian stack.

- Agents write pages through GBrain; GBrain commits and pushes here.
- Obsidian (via the Git plugin) pulls every few minutes, and commits your edits back.
- Dot-folders such as `.obsidian/` are not indexed by GBrain.

Start with the example pages under `people/` and `concepts/`, then delete them when you no longer need them.
